# 半步 · 人格测试 H5

手机浏览器里完成的人格测试。题目、维度、结果都在题库 JSON 里，页面只负责把一套题走完。

## 运行

```bash
cd apps/personality-h5
npm install
npm test
npm run dev
```

浏览器打开 `http://localhost:5173`。`npm run build` 会在 `dist/` 生成可部署的静态文件。

## 结构

- `src/engine`：校验、计分、答题状态。不依赖 React，以后换小程序可以留着。
- `src/content/packs`：题库。现在有「这栋房子」「同屋的人」「三个人的选择」。
- `src/ui`：H5 页面。首页、开场、一题一屏、结果。

首页按 `src/content/registry.ts` 列出题库。再加一套题，放进 `packs/` 并在 registry 登记即可，页面不用改。

## 计分

每道题三个选项，计分是 +1、0、-1。房子里的两套题共用四个方向：先说、看人、边做、直说。「三个人的选择」用另一套坐标：先说、押上、台前、认定。

作答后按维度求和，再除以该维度可能达到的最大绝对值，得到大约 -1 到 1 的向量。

- `axis`：正为高端，负为低端，刚好抵消则视为中间，不硬套类型。「这栋房子」用这个模式。
- `nearest`：和原型向量做余弦相似度，取方向最接近的角色。向量接近 0 时不出角色。「同屋的人」和「三个人的选择」用这个模式。
- `emphasize()`：以后的话题镜头。先给维度乘强调系数，再做最近匹配。例如亲密关系加重冲突，共事加重节奏和判断。

人物卡不进题目表。以后给人物一份同样的四维向量，就可以问「气质接近谁」。两个人怎么相处，另开一套场景卷。

## 现在有的题

主题是一档七天的生活综艺：你和几个陌生人被关在同一栋房子里。

- 这栋房子：12 题，每题三项，16 个原创类型名。结果页用类型名加每个维度的一句解释。
- 同屋的人：同一栋房子，题目换成你怎么对待那个在意的人，结果是 6 个角色之一。
- 三个人的选择：8 题，按黄仁勋、Lori、黄乐的公开选择出题，结果是更靠近谁的做法。材料记在 `src/content/huang-three-lives.md`。
