# 半步 · 人格测试 H5

手机浏览器里完成的人格测试。题目、维度、结果都在题库 JSON 里，页面只负责把一套题走完。

## 运行

```bash
cd apps/personality-h5
npm install
npm test
npm run dev
```

浏览器打开 `http://localhost:5173`。`npm run build` 会在 `dist/` 生成可部署的静态文件。

## 结构

- `src/engine`：校验、计分、答题状态。不依赖 React，以后换小程序可以留着。
- `src/content/packs`：题库。现在有「日常四轴」和「相处角色」。
- `src/ui`：H5 页面。首页、开场、一题一屏、结果。

首页按 `src/content/registry.ts` 列出题库。再加一套题，放进 `packs/` 并在 registry 登记即可，页面不用改。

## 计分

每个选项是一组 `{ 维度 id: 权重 }`，可正可负。正分一端固定为：先说、看人、边做、直说。两套题必须沿用这四个 id 和方向。

作答后按维度求和，再除以该维度可能达到的最大绝对值，得到大约 -1 到 1 的向量。

- `axis`：正为高端，负为低端，刚好抵消则视为中间，不硬套类型。日常四轴用这个模式。
- `nearest`：和原型向量做余弦相似度，取方向最接近的角色。向量接近 0 时不出角色。相处角色用这个模式。
- `emphasize()`：以后的话题镜头。先给维度乘强调系数，再做最近匹配。例如亲密关系加重冲突，共事加重节奏和判断。

人物卡不进题目表。以后给人物一份同样的四维向量，就可以问「气质接近谁」。两个人怎么相处，另开一套场景卷。

## 现在有的两套题

- 日常四轴：12 题，4 个维度，16 个原创类型名。结果页用类型名加每个维度的一句解释。
- 相处角色：同一套坐标，题目换成关系情景，结果是 6 个角色之一。用来证明换 JSON 就能换话题。
